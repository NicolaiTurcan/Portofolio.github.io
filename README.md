# Nicolai Turcan — Portfolio

Personal portfolio: Fullstack developer (React · TypeScript · Node.js) moving into Data Science, ML & AI Engineering.

Live: https://nicolaiturcan.github.io/

## Stack

Plain HTML, CSS and JavaScript — no build step, deployed with GitHub Pages.

- `index.html` — page markup (English is the source text)
- `style.css` — styles; light and dark themes via CSS custom properties
- `i18n.js` — German translations (keys match `data-i18n` attributes)
- `script.js` — theme and language toggles, mobile menu, scroll effects

## Languages

EN / DE toggle in the header. The choice is remembered; German browsers default to DE.
Link straight to a language with `?lang=de` or `?lang=en`.

To change a text: edit the English in `index.html`, then the same key in `i18n.js`.
